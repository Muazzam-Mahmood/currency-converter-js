# Currency Converter JS

An interactive **Currency Converter** web app built with **HTML, CSS, and JavaScript**, using a real‑time exchange rate API — developed as part of my JavaScript learning experience.

---

## 🔗 Live Demo

Check out the live app here:  
- [Currency-Converter](https://muazzam‑mahmood.github.io/currency‑converter‑js/ )

---

## 🕹️ Features

- Convert between different world currencies using current exchange rates  
- Real‑time rate fetching from an external currency API  
- User‑friendly interface with currency selectors and amount input  
- Instant display of conversion results  
- Simple, responsive design

---

## 🛠️ Tech Stack

- **HTML5** — page structure  
- **CSS3** — layout and styling  
- **JavaScript** — API fetching, DOM interaction, and logic  
- **Fetch API** — network requests for exchange rates
